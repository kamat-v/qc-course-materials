# Quantum Computing Course Repository

This repository contains lecture notes, Qiskit notebooks (Python + Colab), and homework sets for an undergraduate course in quantum computing.

The course emphasizes mathematical foundations, building from linear algebra and the postulates of quantum mechanics towards canonical algorithms (Deutsch–Jozsa, Bernstein–Vazirani, Grover, Shor), density matrices, and an introduction to quantum error correction.

The materials are inspired by foundational texts such as Nielsen & Chuang, Yanofsky & Mannucci, Scott Aaronson’s *Quantum Computing Since Democritus*, and the IBM Quantum Learning Platform.

This is part of an ongoing course being taught at Villanova University. The repository will evolve during the semester and continue to be refined in future iterations of the course.
